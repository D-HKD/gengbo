# 更簿 · 執勤記錄

一鍵記錄 **返工、放工、接案件、攞口供、處理案件** 同其他執勤工作嘅時間。
手機優先、離線可用、資料只存喺你自己部電話。

> 香港警察／紀律部隊日常執勤用嘅時間簿。唔使開帳戶、唔使連網、唔會上載任何資料。

---

## 功能

| 功能 | 說明 |
| --- | --- |
| ⏱ 一鍵打卡 | 撳「返工 / 放工」，自動計當值時數 |
| 🗂 12 種工作 | 接案件、攞口供、處理案件、巡邏、交通、拘捕、文書、開會、訓練、用膳、小休、其他 |
| 👆 一撳即計時 | 撳工作掣即刻開始計時；撳返同一個掣即完結，唔使入表 |
| 📁 案件管理 | 新增案件（編號／類別／報案人／地點），每個紀錄可以連結案件，自動累計每單案嘅總工時 |
| ⏳ 即時計時 | 當值時數、進行中工作秒數即時跳動 |
| 📊 統計 | 今日／本週／本月／自訂日期：總當值、OT、當值日數、每日圖表、時間分佈、案件工時 |
| 💰 OT 計算 | 預設每日目標 **9 小時 36 分**（可改），超過即標示 OT；可選擇扣減用膳時間 |
| ✏️ 補錄 / 修改 | 唔記得打卡可以事後補錄，任何紀錄都可以改時間、改類型、加備註 |
| 📤 匯出 | CSV（Excel 開，有每日總結＋明細）、JSON 備份／還原 |
| 🌙 深色模式 | 跟隨系統，亦可手動切換 |
| 📴 離線 | 加到主畫面後完全離線都用得 |

## 點用（手機）

1. 用電話開 GitHub Pages 網址。
2. **iPhone（Safari）**：撳底部「分享」→「加到主畫面」→「加入」。
   **Android（Chrome）**：撳右上角 ⋮ →「安裝應用程式」。
3. 之後撳主畫面個 icon 就開，同普通 App 一樣。

### 日常流程

```
返工  →  撳「返工」
        ├─ 接案件   → 撳「接案件」，填案件資料（自動開始計時）
        ├─ 攞口供   → 撳「攞口供」，揀返邊單案件
        ├─ 處理案件 → 撳「處理案件」，揀案件
        └─ 用膳 / 小休 / 巡邏 …
放工  →  撳「放工」（進行中嘅工作會自動完結）
```

- 撳緊嘅工作會著色，再撳同一個掣就完結。
- 唔記得撳「放工」都唔怕：下次撳「返工」會自動幫你補完上一更。
- 唔記得打卡：去「紀錄」→「補錄」，事後填返時間。

## 私隱

- 所有資料只存喺瀏覽器嘅 `localStorage`，**唔會上載到任何伺服器**。
- 冇帳戶、冇分析、冇追蹤、冇第三方 script。
- 建議：唔好輸入完整身份證號碼或過分敏感嘅個人資料。
- ⚠️ 換電話、清除瀏覽器資料、或者 iPhone 太耐冇開過個 App，資料可能會無咗 —— **記得定期「匯出備份」**（設定 → 匯出備份），會下載一個 JSON 檔。

## OT 點計

```
每日當值 = 由「返工」到「放工」嘅時間（可以有多更）
每日 OT   = max(0, 每日當值 − 每日目標 − 用膳時間[如開啟扣減])
期間 OT   = 逐日 OT 相加（休息日唔計目標，所以唔會出現負數）
```

預設目標 9 小時 36 分，可以喺「設定」改成任何時數。

## 本機開發

純靜態網站，零依賴、零 build step：

```bash
python -m http.server 8080
# 開 http://localhost:8080
```

檔案：

```
index.html      介面 + SVG icon sprite
styles.css      設計系統（深／淺色）
app.js          所有邏輯（儲存、計時、統計、CSV）
manifest.json   PWA manifest
sw.js           Service Worker（離線快取）
icons/          App 圖示
```

## 部署到 GitHub Pages

1. 將呢個資料夾推上 GitHub repo（例如 `gengbo`）。
2. Repo → Settings → Pages → Source 揀 `Deploy from a branch` → Branch `main` / `(root)`。
3. 等一兩分鐘，網址會係 `https://<你的帳號>.github.io/gengbo/`。

Service Worker 只會喺 HTTPS（或 localhost）先行，所以 Pages 上面離線功能先會生效。
